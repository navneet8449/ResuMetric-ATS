# ResuMetric ATS – AI-Powered Resume Analyzer

ResuMetric ATS is an AI-powered resume analysis and job matching application designed to help job seekers evaluate their resumes against specific job descriptions.

It analyzes technical skills, identifies skill gaps, estimates job compatibility scores, and provides actionable suggestions to improve resumes.

## 🚀 Features

- **AI-Powered Resume Analysis:** Analyze resumes using AI.
- **13 Predefined Job Roles:** Choose from multiple industry-specific job roles.
- **Job Description Matching:** Compare resumes against target job requirements.
- **ATS Match Score:** Get an estimated compatibility score out of 100.
- **Skill Gap Analysis:** Identify missing technical skills.
- **Actionable Recommendations:** Receive suggestions for resume improvement.
- **Custom Job Description:** Analyze resumes against your own job descriptions.
- **Interactive UI:** Clean and user-friendly interface with role filters.

## 🛠️ Tech Stack

- TypeScript
- React
- Google Gemini AI
- Vite
- Node.js

## 💡 How It Works

1. Select a predefined job role or provide a custom job description.
2. Enter your resume information.
3. The AI analyzes the resume against job requirements.
4. Review the estimated ATS match score.
5. Identify missing skills and improvement opportunities.

## 🎯 Project Objective

The main objective of ResuMetric ATS is to help candidates understand how well their resumes align with job requirements and improve their chances of passing initial resume screening.
